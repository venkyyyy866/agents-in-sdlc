Pratique o GitHub Copilot em um ciclo de vida de desenvolvimento de software realista usando o aplicativo Tailspin Toys e o backlog correspondente. Escolha o ambiente em que deseja trabalhar e planeje, desenvolva, teste, revise e entregue mudanças significativas.

## Workshops

| Ambiente | Descrição |
|----------|-----------|
| [GitHub Copilot CLI][cli] | Trabalhe no terminal usando modos de agente, skills, ferramentas MCP e automação de pull requests. |
| [Aplicativo GitHub Copilot][app] | Use um espaço de trabalho dedicado para criar, revisar e entregar mudanças com agentes. |
| [Agente de nuvem do GitHub Copilot][cloud] | Delegue tarefas ao agente de nuvem e acompanhe o trabalho assíncrono em pull requests. |
| [Visual Studio Code][vscode] | Desenvolva no VS Code com instruções personalizadas, modos de agente e ferramentas. |
