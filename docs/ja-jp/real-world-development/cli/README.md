**[GitHub Copilot CLI][about-copilot-cli]** を使うと、エージェント型コーディングアシスタントとして GitHub Copilot をターミナルで利用できます。コードベースの調査、コードの生成、コマンドの実行、外部ツールへの接続をコマンドラインから行えるため、グラフィカルエディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys の一連のワークフローに沿って進めます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして使い方を確認します。
2. 星評価の変更を加え、ブラウザーで確認して、最初のプルリクエスト (PR) を手動でマージします。
3. 絞り込みの Issue から始め、Plan モードで方針を決め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示を更新し、絞り込み機能の作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズして、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーで絞り込みの動作を確認します。
7. quality assurance (QA) カスタムエージェントを作成して使い、要件、テスト範囲、検証結果をレビューします。
8. 絞り込みの変更全体をレビューし、Agent Merge を使って PR を処理します。
9. コンテキスト、モデル、共有、任意のクラウド委任に使えるスラッシュコマンドを確認します。

ワークショップを簡潔に進めるため、星評価と絞り込みの 2 つの PR を作成します。指示の更新、スキルの更新、QA プロファイル、テストを含む絞り込みの作業は、各ツールを学ぶ間に前の作業を活用できるよう、1 つの会話とブランチで進めます。

## 前提条件

ワークショップに参加する前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドライン操作の基本的な知識

> [!TIP]
> 有料プランがない場合でも、認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使用するエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれます。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合は、管理者が Copilot CLI を有効にしていることを確認してください。
